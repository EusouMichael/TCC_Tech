Contexto do Projeto

A Escola Tech e seus Desafios

🏫 Quem é a Escola Tech?

  • Instituição de ensino em tecnologia
  • 6 cursos: AWS, Data Science, Full Stack, Cybersecurity, IA, UX/UI
  • Site institucional como canal principal de matrículas
  • Picos de acesso concentrados em períodos de inscrição

⚠️ Problemas On-Premises

  • Servidor único — ponto único de falha
  • Sem escalabilidade para picos de tráfego
  • Manutenção manual de hardware e SO
  • Sem proteção WAF ou DDoS
  • Backup sem automação garantida
  • Indisponibilidade durante períodos de matrícula

✅ Objetivos na AWS

  • Eliminar ponto único de falha (Multi-AZ)
  • Escalonamento automático (ASG)
  • HTTPS ponta-a-ponta (ACM + CloudFront)
  • Proteção WAF + Shield Standard
  • Monitoramento proativo (CloudWatch)
  • Infraestrutura como Código (Terraform)
  • Backup automatizado (AWS Backup)

💡 SO escolhido: Amazon Linux 2023 — recomendação atual da AWS, usa dnf, sem dependências legadas.

🔀 Roteamento

  • 1 Internet Gateway por VPC
  • 2 NAT Gateways — 1 por AZ (HA)
  • Route Table pública → IGW
  • Route Table privada → NAT GW local
  • ALB nas subnets públicas
  • EC2 nas subnets privadas
  • VPC Flow Logs habilitados (30 dias)

NAT Gateway × 2 representa ~25% do custo total (~$39/mês). Single NAT economiza ~$16/mês mas elimina redundância por AZ.

Segurança em Camadas

Proteção da Aplicação

🛡️

AWS WAF — 5 regras gerenciadas

OWASP Top 10, SQLi, inputs maliciosos, IPs com má reputação e rate limiting (2000 req/5min por IP). Associado ao CloudFront — inspeciona na borda.


~$10,60/mês
🔰

Shield Standard

Proteção automática contra DDoS Layer 3/4 em CloudFront, ALB e Route 53. Incluso sem custo adicional em todos os serviços AWS.


Gratuito
🔑

Custom Header Secreto

CloudFront injeta X-CF-Origin-Secret com valor aleatório gerado pelo Terraform. ALB rejeita (403) qualquer requisição sem esse header — impede bypass do WAF.


Sem custo
🔐

Security Groups

SG ALB: aceita 80/443 da internet. SG EC2: aceita 80 apenas do SG ALB. Sem SSH exposto — acesso via SSM Session Manager.


Incluso

📊 Como funciona o Target Tracking

  • ASG monitora a CPU média de todas as instâncias
  • Adiciona instâncias se CPU média > 70%
  • Remove instâncias se CPU média cai (sem forçar abaixo de min=2)
  • Nenhuma intervenção manual necessária

🔄 Bootstrap automático

  • Cada nova EC2 executa user_data.sh.tpl no boot
  • Instala Nginx via dnf (AL2023)
  • Busca index.html do S3 (aws s3 cp)
  • Valida /health antes de registrar no ALB
Deployment do Site

Como o site chega a cada EC2

📤 Terraform faz o upload

resource "aws_s3_object" "index_html" { bucket = aws_s3_bucket.assets.id key = "site/index.html" source = "../05-website/index.html" etag = filemd5("../05-website/index.html") }

O terraform apply faz o upload do index.html para o S3. Toda vez que o arquivo mudar, um novo apply o atualiza.

📥 EC2 busca no bootstrap

# user_data.sh.tpl (executado no boot) aws s3 cp \ s3://$BUCKET/site/index.html \ /var/www/html/index.html # Fallback se S3 indisponível: # serve página de placeholder

🔄 Toda nova instância criada pelo ASG recebe o site automaticamente — sem upload manual.

Performance e DNS

CloudFront + Route 53

⚡

Amazon CloudFront

  • Edge locations globais (PriceClass_All)
  • Cache de assets estáticos: TTL 86400s (24h)
  • Conteúdo dinâmico: TTL 0 (sem cache)
  • Compressão gzip/brotli automática
  • HTTP → HTTPS redirect (viewer protocol)
  • TLSv1.2_2021, cert ACM us-east-1
  • WAF associado na borda
🌐

Amazon Route 53

  • Hosted Zone para o domínio
  • Registros A/AAAA (apex e www) → alias CloudFront
  • Health Check HTTPS /health, 30s
  • Pré-requisito: domínio registrado + DNS delegado
  • Sem domínio: usar output cloudfront_domain_name

Não há failover ativo/passivo configurado. Resiliência é provida pelo ALB + ASG Multi-AZ.

Infraestrutura como Código

Terraform

📁 Arquivos .tf

  • main.tf — provider AWS + Random + data sources
  • vpc.tf — VPC, subnets, IGW, NAT, route tables
  • security.tf — SGs, WAF, ACM, IAM, header secreto
  • ec2.tf — Launch Template + ASG + Target Tracking
  • alb.tf — ALB, Target Group, listeners
  • cloudfront.tf — CDN, cache policies, OAC
  • route53.tf — Hosted Zone, records, health check
  • s3.tf — 3 buckets + upload do index.html
  • monitoring.tf — CloudWatch, SNS, AWS Backup
  • user_data.sh.tpl — bootstrap AL2023

✅ Benefícios IaC

  • Reproducibilidade total do ambiente
  • Versionamento via Git
  • terraform plan mostra mudanças antes de aplicar
  • Rollback via Git + novo apply
  • Documentação implícita na infraestrutura
cd 04-terraform terraform init terraform validate terraform plan -var-file=terraform.tfvars terraform apply -var-file=terraform.tfvars # Destruir após a apresentação: terraform destroy

Lições e Próximos Passos

✅ O que funcionou bem

  • Terraform tornou a infraestrutura reproducível e auditável
  • AMI via SSM Parameter garante AL2023 atualizado sem fixar ID
  • Custom header secreto protege o ALB sem custo adicional
  • Bootstrap via S3 garante que o ASG funcione de forma autônoma
  • AWS Backup eliminou necessidade de cron manual
  • AL2023 com dnf: sem dependências legadas do AL2

🚀 Próximos Passos

  • CI/CD com CodePipeline + CodeDeploy para deploy automático
  • EC2 Reserved Instances (1 ano) para reduzir custo em ~40%
  • VPC Endpoints para S3 e SSM (reduz tráfego NAT)
  • HTTPS CloudFront→ALB com subdomínio de origem dedicado
  • AWS Config para auditoria de conformidade de recursos
  • CloudFront Functions para headers de segurança reais
